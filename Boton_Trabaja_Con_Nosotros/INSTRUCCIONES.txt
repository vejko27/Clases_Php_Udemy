INSTRUCCIONES DE INSTALACIÓN - FORMULARIO TRABAJA CON NOSOTROS
================================================================

PASO 1: CREAR LA BASE DE DATOS
===============================
1. Abre tu navegador y ve a: http://localhost/phpmyadmin
2. Inicia sesión (usuario: root, sin contraseña)
3. En el panel izquierdo, busca la opción "Nueva" o "Create"
4. Crea una nueva base de datos llamada: trabaja_con_SBC
5. Después de crear la BD, selecciónala
6. Ve a la pestaña "SQL" en la parte superior
7. Copia todo el contenido del archivo "base_datos.sql"
8. Pégalo en la ventana de SQL y haz clic en "Ejecutar"
9. Verás que se crea la tabla "candidatos"

ALTERNATIVA - Usando línea de comandos:
1. Abre CMD o PowerShell
2. Ve a tu carpeta XAMPP/mysql/bin
3. Ejecuta: mysql -u root < ruta/del/archivo/base_datos.sql

PASO 2: VERIFICAR LOS ARCHIVOS
================================
Los siguientes archivos deben estar en: C:\xampp\htdocs\Clases_Php_Udemy\Boton_Trabaja_Con_Nosotros\

✓ index.html - El formulario
✓ syles_tnosotros.css - Estilos del formulario de postulaciones
✓ base_datos.sql - Estructura de la base de datos
✓ composer/composer.json y composer/composer.lock - Dependencia de PHPMailer
✓ vendor/ - Se genera al instalar las dependencias con Composer
✓ PHPMailer-master/ - Biblioteca PHPMailer descargada para el envío SMTP
✓ cvs/ - Carpeta donde se guardarán los CVs (se crea automáticamente)
✓ php/procesar.php - Script que procesa y guarda los datos
✓ config/correo.php - Configuración SMTP local (no se sube al repositorio)
✓ config/.htaccess - Bloquea el acceso web a los archivos de configuración

PASO 3: INICIAR XAMPP
======================
1. Abre el Panel de Control de XAMPP
2. Inicia el servicio MySQL
3. Inicia el servicio Apache

CONFIGURAR PHPMailer Y EL CORREO
================================
1. Mantén la carpeta PHPMailer-master, incluida su subcarpeta src, en la raíz
   del proyecto. php/procesar.php carga directamente Exception.php, SMTP.php
   y PHPMailer.php desde esa carpeta; no hace falta ejecutar Composer para
   enviar correos.
2. Abre config/correo.php y escribe la contraseña SMTP en la opción "password".
   Para una instalación nueva, copia config/correo.example.php como
   config/correo.php y completa allí la contraseña. No la escribas en
   php/procesar.php ni la subas al repositorio.
3. config/correo.php está excluido de Git y protegido contra acceso web por
   config/.htaccess. En el hosting, sube el archivo config/correo.php por el
   administrador de archivos o SFTP y completa allí las credenciales de ese
   servidor; nunca publiques ese archivo en Git.

El envío usa smtp.office365.com por el puerto 587 con STARTTLS. Si el envío
falla, verifica que SMTP AUTH esté habilitado para la cuenta en Microsoft 365.
Las notificaciones se envían desde impresora1@gruposbc.com.pe a
victor.canova@gruposbc.com.pe e incluyen el CV adjunto.

En hosting Apache, conserva la protección config/.htaccess. Si el hosting usa
Nginx o no respeta archivos .htaccess, guarda config/correo.php fuera de la raíz
web y ajusta su ruta de carga antes de publicar el sitio.

PASO 4: PROBAR EL FORMULARIO
=============================
1. Abre tu navegador y ve a: http://localhost/Clases_Php_Udemy/Boton_Trabaja_Con_Nosotros/
2. Completa el formulario con tus datos
3. Adjunta un archivo PDF, DOC o DOCX
4. Haz clic en "Enviar Candidatura"
5. Deberías ver un mensaje de éxito

PASO 5: RECIBIR Y REVISAR POSTULACIONES
========================================
Las postulaciones se revisan desde el correo victor.canova@gruposbc.com.pe.
Cada notificación incluye los datos del postulante y su CV adjunto. La gestión
de las postulaciones se realiza únicamente desde el correo electrónico.

Los registros también se guardan en la tabla "candidatos" de la base de datos.
Los CV se conservan en la carpeta:
C:\xampp\htdocs\Clases_Php_Udemy\Boton_Trabaja_Con_Nosotros\cvs\

CONSIDERACIONES IMPORTANTES
============================
1. Usuario MySQL: root
2. Contraseña MySQL: (sin contraseña, deja en blanco)
3. Host: localhost
4. Base de datos: trabaja_con_SBC

Si necesitas cambiar estos datos, edita el archivo "php/procesar.php" en estas líneas:
    $servername = "localhost";
    $username = "root";
    $password = "";
    $dbname = "trabaja_con_SBC";

SOLUCIÓN DE PROBLEMAS
======================

Problema: "Error de conexión a la base de datos"
Solución: 
- Verifica que MySQL esté corriendo en XAMPP
- Asegúrate de que la BD "trabaja_con_SBC" existe
- Verifica los datos de conexión en php/procesar.php

Problema: "Error al subir el archivo"
Solución:
- Verifica que la carpeta "cvs" tenga permisos de escritura
- La carpeta "cvs" está en la raíz del proyecto, al mismo nivel que index.html
- Comprueba que el archivo sea PDF, DOC o DOCX
- Asegúrate de que el archivo no supere 5MB

Problema: "Error 404 php/procesar.php no encontrado"
Solución:
- Verifica que php/procesar.php esté dentro de la carpeta php
- Recarga la página con Ctrl+F5 para limpiar caché

CAMPOS DE LA BASE DE DATOS
===========================
- id: Identificador único de cada candidato
- nombres: Nombres completos del candidato
- apellidos: Apellidos completos del candidato
- email: Correo electrónico (no se pueden repetir)
- disposicion: Puesto al que postula el candidato
- cv_nombre: Nombre original del archivo CV
- cv_ruta: Ruta donde se guardó el archivo
- fecha_registro: Fecha y hora del registro
- estado: Estado de la candidatura (nuevo, revisado, rechazado, seleccionado)
- notas: Campo para agregar notas internas
